How to use
  1. Select the original, unmodified GPX from BRouter or your planner.
  2. Save the generated file ending in _Onelap_CN_precorrected.gpx.
  3. Import that generated file into mainland Chinese OnelapFit (顽鹿运动).
  4. Check the line on the map, then test GPS breadcrumb alignment before a long ride.
Important: This file is deliberately pre-shifted. Do not open it as a normal route in global OnelapFit, BRouter, Strava or other navigation apps. Do not run a corrected file through this converter twice.
Uses the numerical inverse of WGS-84 → GCJ-02 → BD-09, verified against a 44.9 km Singapore GPX and Chinese Onelap route export on 8 Oct 2026. All processing happens locally on your device.
